# 🚀 Open.Code — Surgical AI File Editor (PowerShell Edition)
## 🛡️ محرك التعديل الجراحي الذكي للمشاريع والأكواد v4.0 (Enterprise)

> **Branch:** `PowerShell`  
> **Architecture:** Local File Bridge & Surgical Diff Engine (Aider Paradigm)  
> **Verdict:** معمارية إنتاجية معتمدة تفصل تماماً بين "التحليل البرمجي للذكاء الاصطناعي" و"التحكم المحلي في القرص الصلب".

---

### 🌟 المميزات المعمارية الرئيسية (Core Highlights):

* 🎯 **محرك المطابقة الخماسي الحتمي (5-Level Resilient Matcher):**
  - **Level 1 (Exact Match):** مطابقة سريعة وفورية.
  - **Level 2 (Windows CRLF/EOL Normalization):** حل جذري لمشكلة نهايات الأسطر بين Windows و Unix.
  - **Level 3 (Whitespace Collapse):** تطبيع المسافات والتبويبات المنهارة لمنع فشل المطابقة التافه.
  - **Level 4 (Fuzzy Window Match > 82%):** مطابقة ضبابية ذكية في حال أجرى الموديل تغييرات مسافات طفيفة.
  - **Level 5 (Explicit Fail-Fast):** فشل صريح وفوري لمنع التخمين الخاطئ وحماية سلامة الكود بنسبة 100%.

* 🛡️ **صمام الأمان النحوي التلقائي (AST Syntax Gate):**
  - فحص كود بايثون في الذاكرة فورياً بـ `ast.parse` قبل أي عملية كتابة على الهارد ديسك لمنع حفظ أكواد مكسورة.

* 📂 **المعاملات الذرية وتعدد الملفات (Multi-File Atomic Transactions):**
  - دعم تعديل عدة ملفات في مسارات مختلفة داخل مهمة واحدة عبر ترويسات `FILE: path/to/file`.
  - تطبيق التراجع الكامل (Full Rollback) في حال فشل مطابقة أي كتلة في أي ملف، لضمان عدم ترك المشروع في حالة مشوهة.

* ⚡ **استجابة صاروخية واقتصاد التوكنز:**
  - استجابة في 2 إلى 3 ثوانٍ فقط بدلاً من إعادة كتابة الملفات بالكامل.
  - توفير أكثر من 80% من التوكنز المستهلكة.

### 🕹️ طريقة التشغيل السريع (Quick Start):

#### 1. التشغيل بالماوس (Drag & Drop):
* اضغط دبل كليك على: `تشغيل_معدل_الملفات_المعزول.bat`
* اسحب أي ملف وأفلته داخل النافذة واكتب التعليمات المطلوب تنفيذها.

#### 2. سطر الأوامر (CLI):
```powershell
# تعديل ملف واحد
python file_editor_agent.py "path/to/file.py" -p "صلح الخطأ الحسابي واضف دالة جديدة" --auto-save

# تعديل ملفات متعددة في نفس المهمة
python file_editor_agent.py "file1.py" "file2.py" -p "اربط الملفين ببعض ونظف الاستيرادات"

# تشغيل وضع المراقبة اللحظية (Auto Watcher on Ctrl+S)
python file_editor_agent.py "path/to/file.py" --watch
```

#### 3. تشغيل حزمة الاختبارات الذاتية:
```powershell
python test_engine.py
```
